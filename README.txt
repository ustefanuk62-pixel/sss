Как запустить сайт на панели (Pterodactyl, Node.js)

Ошибка "Cannot find module '/home/container/index.js'" означает, что на сервере нет файла index.js.
В этой папке он есть: это маленький сервер, который раздаёт твой сайт.

Что загрузить в файловый менеджер панели (в корень сервера, туда, где /home/container):
  index.js        сервер
  package.json    описание (пакеты ставить не нужно)
  public/         папка с сайтом

В папке public лежит index.html. Замени его своим файлом index.html (тем, где вставлены тексты).
Если у твоего index.html есть папка assets (обложки и музыка), положи её рядом: public/assets/.

В настройках запуска (Startup) должно быть:  JS_FILE = index.js  (это значение по умолчанию).
Нажми Start. В консоли появится: "Сайт запущен на порту ...".
Сайт открывается по адресу  http://АДРЕС_СЕРВЕРА:ПОРТ  (адрес и порт смотри на вкладке Console или Network в панели).

Порт сервер берёт сам из панели (переменная SERVER_PORT), ничего вписывать не нужно.
Выкладывай в открытый доступ только то, что тебе можно публиковать.


--- Регистрация, вход, счётчик, скачивание ---

Что добавлено:
  * Регистрация и вход (кнопка «Войти» справа вверху). Вход запоминается в cookie на 30 дней,
    пароли хранятся только в виде хэша.
  * Счётчик зарегистрированных пользователей внизу по центру главного экрана.
  * Кнопка ⬇ в плеере: скачивает песню с красивым именем «Артист - Название.mp3».

Где хранятся данные:
  Папка data/ рядом с index.js (создаётся сама): users.json (аккаунты) и sessions.json (входы).
  НЕ удаляй её и не выкладывай никуда: там аккаунты пользователей. Делай её копию, если важно.
  Папка data/ не раздаётся через сайт, скачать её по ссылке нельзя.

Скачивание только для вошедших:
  В index.js вверху есть строка  REQUIRE_LOGIN_FOR_DOWNLOAD = true;
  Поставь false, если хочешь, чтобы скачивать могли все без входа.

Новая песня: положи assets/N.mp3 (N = номер) и добавь её в TRACKS в index.html с id "tN".
  Скачивание найдёт файл по номеру само.

Важно про https: если сайт открыт через https (например, за прокси/Cloudflare), cookie входа
автоматически станет Secure. Если сайт открыт по http://IP:порт, всё тоже работает.

Починено: песня «Ты любишь сво» не играла, потому что файл назывался 4.mp4, а сайт искал 4.mp3.
  Я сконвертировал звук в assets/4.mp3 (старый 4.mp4 убран).


--- База данных MySQL ---

Аккаунты и входы теперь хранятся в MySQL (панель → Databases), а не в папке data/.

1. Открой db.json и впиши:
     user      - Username из панели (скопируй, не переписывай руками)
     password  - нажми значок глаза в панели у базы и скопируй пароль
   host и database уже заполнены (mysql.play2go.cloud, s32855_Playlist).
2. Загрузи на сервер: index.js, package.json, db.json, public/.
3. Нажми Start. При запуске сервер сам выполнит npm install (поставит mysql2) и создаст таблицы users и sessions.
   В консоли должно появиться: "MySQL подключена", затем "Сайт запущен на порту ...".
4. Если раньше уже были аккаунты в data/users.json, оставь эту папку на месте:
   при первом запуске они один раз перенесутся в базу (входы придётся выполнить заново).

Если пишет "НЕ УДАЛОСЬ подключиться к MySQL": проверь user и password в db.json.
Сайт при этом всё равно запустится, но регистрация и вход работать не будут.

Никому не показывай db.json и не выкладывай его на GitHub: там пароль от базы.
