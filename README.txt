Как запустить сайт на панели (Pterodactyl, Node.js)

Ошибка "Cannot find module '/home/container/index.js'" означает, что на сервере нет файла index.js.
В этой папке он есть: это маленький сервер, который раздаёт твой сайт.

Что загрузить в файловый менеджер панели (в корень сервера, туда, где /home/container):
  index.js        сервер
  package.json    описание (пакеты ставить не нужно)
  public/         папка с сайтом

В папке public лежит index.html. Замени его своим файлом index.html (тем, где вставлены тексты).
Если у твоего index.html есть папка assets (обложки и музыка), положи её рядом: public/assets/.

В настройках запуска (Startup) должно быть:  JS_FILE = index.js  (это значение по умолчанию).
Нажми Start. В консоли появится: "Сайт запущен на порту ...".
Сайт открывается по адресу  http://АДРЕС_СЕРВЕРА:ПОРТ  (адрес и порт смотри на вкладке Console или Network в панели).

Порт сервер берёт сам из панели (переменная SERVER_PORT), ничего вписывать не нужно.
Выкладывай в открытый доступ только то, что тебе можно публиковать.
